# Collection microbenchmarks

Raw samples, all sizes and collection-retention observations are archived alongside this report. Input creation, delegates, correctness assertions and serialization are outside the timed loops. Each cell has eight batches of repeated operations after 256 warm-up operations. GC columns are batch totals, not normalized collections per operation.

The LINQ controls reproduce the original collection pipelines. Repeated collector Detach includes its lock and existing completeness flags; the five-array LINQ control excludes that lock and is not an exact old-collector timing. Candidate tests start with precomputed identity strings, so symbol display/identity construction is deliberately excluded. Diagnostic tests isolate key deduplication and immutable result construction, not Roslyn diagnostic queries or message formatting.
