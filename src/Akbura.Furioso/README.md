# Akbura.Furioso

> [!IMPORTANT]
> Akbura.Furioso is archived and is no longer used as the Akbura production compiler.

Furioso is kept only as a historical implementation and compatibility baseline for tests and benchmarks. It is not shipped by the `Akbura` package and must not be used by new applications. The active production compiler is `Akbura.BlackSilence`.
